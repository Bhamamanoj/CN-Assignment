# Assignment
Assignment - 1

## Title
How the Internet Delievers a Webpage

## Objective
To understand how a web page is delivered from a web server to a browser using the TCP/IP protocol stack and protocols such as DNS, HTTP, and TCP.

## Solution
The process of accessing Google Search is studied, including DNS resolution, HTTP communication, TCP reliability, Client–Server architecture, cookies, and the comparison between HTTP and FTP.

## Output
The browser successfully receives and displays the webpage through the process:
URL → DNS → TCP → HTTP Request → Server Response → Webpage

## Conclusion
The assignment demonstrates how different Internet protocols work together to deliver webpages efficiently and reliably to users.
